# Tugas-2-Deep-Learning
Proyek ini mengimplementasikan Deep Learning untuk mengklasifikasi kesegaran apel dan pisang (Segar/Busuk). Menggunakan arsitektur EfficientNet-B0 dengan PyTorch, model mencapai akurasi 99%. Repositori mencakup eksperimen hyperparameter tuning (LR &amp; Batch Size), evaluasi Confusion Matrix, dan visualisasi Grad-CAM untuk transparansi prediksi model.
